# TradeSim

## Algorithmic Trading and Market Simulation Platform

TradeSim is a C/C++ based market simulation project developed as part of Project-Based Learning (PBL).

The project simulates a simplified trading environment where virtual traders can place buy and sell orders. The system maintains an order book, matches compatible orders using price-time priority, records executed trades, and updates virtual portfolios.

## Main Components

- Order Management
- Order Book
- Matching Engine
- Trade Records
- Portfolio Management
- Market Simulation
